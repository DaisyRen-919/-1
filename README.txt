北京市家校沟通与投诉规范平台（离线网页包）
================================================

这是一个用于辅助人大议案落实的机制网站原型，不是议案内容展示页。

快速打开
--------
1. macOS：双击“启动网站.command”。
2. Windows：双击“启动网站.bat”。
3. 也可以直接双击“index.html”，从身份入口进入演示页面。

网站结构
--------
- index.html：演示登录与身份选择入口
- home.html：机制介绍首页与四端入口
- pages/parent.html：家长沟通、反馈提交、记录查询
- pages/teacher.html：教师留痕、权益反馈、证据包与支持服务
- pages/school.html：学校受理、分级处置、档案和数据导出
- pages/admin.html：区域看板、风险复核、内部信用记录与联席协调
- css/style.css：全站样式
- js/main.js：离线交互和浏览器本地数据
- docs/使用说明.txt：详细操作说明

数据说明
--------
- 网站中所有人物、编号、事项和统计均为演示数据。
- 新增沟通和反馈只保存在当前浏览器 localStorage 中，不会上传。
- 登录身份也只保存在当前浏览器中；这是一套演示身份切换，并非真实身份认证。
- 在首页或页脚点击“重置演示数据”可清除新增演示记录。
- 正式上线前仍需接入身份认证、数据库、文件存储、权限审计与安全测评。

更新现有 GitHub Pages 网站
--------------------------
1. 解压本文件包，打开“北京市家校沟通与投诉规范平台-离线版”文件夹。
2. 登录 GitHub，进入仓库 https://github.com/DaisyRen-919/-1 。
3. 点击“Add file”→“Upload files”，把文件夹里面的全部文件和文件夹上传到仓库根目录（不要只上传最外层文件夹）。
4. 页面提示同名文件时保留本次新文件，填写说明后点击“Commit changes”。
5. 等待约1至3分钟，再刷新 https://daisyren-919.github.io/-1/ 。

提示：GitHub Pages 在中国大陆不同网络中的连通性可能有差异；本次修改提升了微信内置浏览器的页面兼容性，但无法控制运营商对 github.io 域名的网络策略。
