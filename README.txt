北京市家校沟通与投诉规范平台（离线网页包）
================================================

这是一个用于辅助人大议案落实的机制网站原型，不是议案内容展示页。

快速打开
--------
1. macOS：双击“启动网站.command”。
2. Windows：双击“启动网站.bat”。
3. 也可以直接双击“index.html”，大部分功能可直接使用。

网站结构
--------
- index.html：机制首页与四端入口
- pages/parent.html：家长沟通、反馈提交、记录查询
- pages/teacher.html：教师留痕、权益反馈、证据包与支持服务
- pages/school.html：学校受理、分级处置、档案和数据导出
- pages/admin.html：区域看板、风险复核、内部信用记录与联席协调
- css/style.css：全站样式
- js/main.js：离线交互和浏览器本地数据
- docs/使用说明.txt：详细操作说明

数据说明
--------
- 网站中所有人物、编号、事项和统计均为演示数据。
- 新增沟通和反馈只保存在当前浏览器 localStorage 中，不会上传。
- 在首页或页脚点击“重置演示数据”可清除新增演示记录。
- 正式上线前仍需接入身份认证、数据库、文件存储、权限审计与安全测评。
